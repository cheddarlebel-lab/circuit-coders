CIRCUIT CODERS - metal QR business card
=======================================
Blank    : 86 x 54 mm  (laser ablates the surface -> bright silver)
Machine  : Bambu H2C, 40W laser, Bambu Suite

FILES
  cc-card-ENGRAVE.png  <- IMPORT THIS. Fits the 86 x 54mm card. Black = engrave->silver.
  cc-card-PREVIEW.png  <- Finished look (QR verified -> https://circuitcoders.com).

PREFER THE READY-MADE PROJECT
  cc-card-stainless.lac already carries the proven recipe + art. Open it in
  Bambu Suite and hit Make - no import or sizing needed. Steps below are the
  manual fallback only.

BAMBU SUITE (manual fallback)
  1. New laser project. Import cc-card-ENGRAVE.png.
  2. Process type: Laser Image (raster) engrave.
  3. Size to the blank: 86 x 54 mm. Wipe the blank clean first.
  4. Place blank flat on bed. Run auto-focus / height probe.
  5. Glasses on, enclosure closed, exhaust on.

SETTINGS
  Coated VMYTH 304 stainless: use cc-card-stainless.lac (22% / 500 mm/s /
  0.06 interval / per-line 2 / air ON) - the dialed-in recipe from the
  LaneTab run. Trim ladder: too warped -> 20, then speed 550. Too light -> 24.
  Bare black anodized aluminum: start ~30-45% / 400-700 mm/s and test first.

QR encodes: https://circuitcoders.com  (low density - very robust)
